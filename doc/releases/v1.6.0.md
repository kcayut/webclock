# WebClock 1.6.0

## 更新重點

- **用 AI 助理設定鬧鐘與行程。** 在助理所在的電腦執行 WebClock MCP，使用「程式存取」核發的憑證選定可指派的群組與裝置。助理可建立一次性鬧鐘、WebClock 本地行程，以及隨行程改期的提前提醒。Server 套件內含 `scripts/webclock_mcp.py`、`scripts/control_clock.py` 和選用的 `scripts/skills/webclock/`。[WebClock MCP 安裝與連線測試](https://github.com/kcayut/webclock/blob/v1.6.0/doc/guides/mcp.md)
- **EE04 桌鐘可跳過下一次每日鬧鐘。** 略過後其餘日期仍照原排程響鈴，原定時間前可選擇恢復。請從同版 Git 原始碼的 `firmware/ee04-clock/` 取得 ESPHome 設定並依說明刷機。[EE04 韌體與使用手冊](https://github.com/kcayut/webclock/tree/v1.6.0/firmware/ee04-clock)

## 升級

Linux 與 Docker 主機請先備份資料。自用模式可在「版本更新」留空金鑰檢查新版，按「立即升級」時才需輸入主機核發的自用更新金鑰。Home Assistant App 由 Supervisor 更新，整合與卡片由 HACS 更新。[啟用更新服務、設定金鑰與復原](https://github.com/kcayut/webclock/blob/v1.6.0/doc/operations/update-operations.md)
