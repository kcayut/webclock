# WebClock 1.1.0

首個公開 Release，將 Linux、Docker、Home Assistant App 與 HACS 整合統一為 **1.1.0**。沿用既有 HA 版號，避免已安裝的版本倒退。

## 一行安裝

Linux／Raspberry Pi（Debian、Ubuntu 或 Raspberry Pi OS，使用 systemd）：

```bash
curl -fsSL https://github.com/kcayut/webclock/releases/latest/download/install.sh -o /tmp/webclock-install.sh && bash /tmp/webclock-install.sh
```

Docker（先安裝並啟動 Docker／Compose）：

```bash
curl -fsSL https://github.com/kcayut/webclock/releases/latest/download/install.sh -o /tmp/webclock-install.sh && bash /tmp/webclock-install.sh --docker
```

安裝器固定取得正式版，保留設定與未完成安裝的資料，完成健康檢查後列出網址。Docker 直接下載同版映像，主機不需 Git 或 Python。預設 self；需要管理員登入與逐台授權時，使用 `--managed` 與有效 TLS 憑證。[完整安裝與 HTTPS 步驟](https://github.com/kcayut/webclock/blob/v1.1.0/doc/installation.md)

Home Assistant 使用者可[加入 App 來源](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fkcayut%2Fwebclock)，或[透過 HACS 安裝整合與卡片](https://my.home-assistant.io/redirect/hacs_repository/?owner=kcayut&repository=webclock&category=integration)。

## 本版提供

- 時間、日期與星期優先顯示；繁體中文、English、日文管理介面。
- 行事曆、文字提醒、網頁鬧鐘、顯示設定、群組與逐台裝置授權。
- self／managed 與多帳號管理；HA App 管理入口使用 HA Ingress。
- 可選密碼加密的完整 `.webclock` 備份，支援跨主機及 HA App 搬家。
- 安裝前環境／連接埠／TLS 檢查、失敗重試、HTTP／HTTPS 健康檢查與完整網址。
- Linux 安全更新器跟隨最新正式 Release，Docker 固定版號更新；`/api/health` 可核對產品版本。

## 下載選擇

| 檔案 | 用途 |
| --- | --- |
| `install.sh` | 固定安裝本版的一行安裝器 |
| `webclock-1.1.0.tar.gz` | Server 程式與 Docker 部署檔 |
| `webclock-clock-1.1.0.zip` | 電腦離線時鐘；完整解壓後開啟最外層 `index.html`，不用安裝 Server |
| `SHA256SUMS` | 上述下載檔的 SHA256 核對值 |

容器映像為 `ghcr.io/kcayut/webclock:1.1.0` 與 `ghcr.io/kcayut/webclock-addon:1.1.0`，皆提供 `linux/amd64` 與 `linux/arm64`。

## 更新與已知限制

更新前先保存完整備份。既有 Linux 安裝使用安全更新器；Docker 在 `.env` 設定本版 `WEBCLOCK_VERSION=1.1.0` 後執行 `docker compose pull && docker compose up -d --no-build`；App 與 HACS 各自在原安裝入口更新。[更新說明](https://github.com/kcayut/webclock/blob/v1.1.0/doc/installation.md#update)

HA App 仍標示 `experimental`。CI 的容器／ARM 模擬測試不等於 HA OS 商店、HACS 下載、ARM 主機、通知／揚聲器或 iPad mini 1／iOS 9 的實機驗收。網頁鬧鐘須保持瀏覽器在前景、螢幕開啟；離線 ZIP 使用裝置時間，不提供 Server 功能。managed 安裝需要自己準備裝置信任的 HTTPS 憑證。[最新驗證紀錄](https://github.com/kcayut/webclock/blob/main/doc/ha-release.md)
