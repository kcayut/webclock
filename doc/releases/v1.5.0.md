# WebClock 1.5.0

Server、Docker、HA App、HACS 整合與卡片使用相同版號。

## 更新重點

- 顯示設定新增「時鐘樣式」分頁，提供經典大字、翻頁鐘與七段電子鐘三款樣式，各具深色與淺色色盤。
- 管理頁提供固定範例時間的即時預覽，可切換橫向／直向與範例訊息；切換樣式或色彩模式只改草稿，按「儲存樣式」才寫入伺服器。
- 樣式與色彩模式依「裝置 → 群組 → 全體預設」繼承，群組與裝置頁可選擇沿用或自訂；儲存只更新樣式與色彩，不提交其他草稿。
- 舊版「跟隨樣式」設定不再顯示，既有值以深色呈現；未納入本版的樣式在讀取、備份還原與更新健康檢查時回退為經典大字。
- 夜間時段仍使用深色色盤；低亮度與黑畫面行為不變，管理預覽會標示未套用黑畫面／亮度。
- 更新 Service Worker 快取清單，離線時鐘 ZIP 仍可正常啟動；補充時鐘樣式相關文件與 API 說明。

## 既有安裝升級

更新前請先保存完整備份。

Linux 在既有安裝目錄執行：

```bash
sudo bash update_clock.sh
```

Docker 使用固定版本入口：

```bash
sudo bash docker_update.sh --check
sudo bash docker_update.sh
```

HA 請先備份，更新 App 後再更新 HACS 整合、重啟 HA 並重新載入卡片。完整流程見[更新維護](https://github.com/kcayut/webclock/blob/v1.5.0/doc/operations/update-operations.md)。

## 下載與新安裝

[完整安裝指南](https://github.com/kcayut/webclock/blob/v1.5.0/doc/installation.md)提供 Linux／Raspberry Pi、Docker、HA App、HACS 與離線時鐘步驟。

| 檔案 | 用途 |
| --- | --- |
| `install.sh` | 固定安裝本版的新安裝入口 |
| `portable_docker_update.sh` | 舊 Docker 升級與同版 worker／救援維護 |
| `webclock-1.5.0.tar.gz` | Server 程式與 Docker 部署檔 |
| `webclock-clock-1.5.0.zip` | 完整解壓後開啟 `index.html` 的離線時鐘 |
| `SHA256SUMS` | 上述下載檔的 SHA256 核對值 |

容器映像：`ghcr.io/kcayut/webclock:1.5.0`、`ghcr.io/kcayut/webclock-addon:1.5.0`；提供 `linux/amd64` 與 `linux/arm64`。

## 驗證界線

HA App 仍為 `experimental`。Docker Desktop、NAS、rootless／遠端 daemon 不在更新器支援範圍。CI、公開下載驗證與實機驗收分開記錄；HA OS 商店／HACS 實際更新、實體 ARM、斷電、音訊及舊 iPad 仍需實機驗證。iPad mini 1／iOS 9.3.5／9.3.6 的時鐘樣式實機驗收仍待完成。[最新發行證據](https://github.com/kcayut/webclock/blob/main/doc/ha-release.md)
