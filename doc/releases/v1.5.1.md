# WebClock 1.5.1

## 更新重點

- 自用模式可從「版本更新」檢查 GitHub Release。安裝新版時輸入主機簽發的更新金鑰，無須建立帳號或切換管理模式。主機管理員仍可決定更新管道與是否自動安裝。
- Linux 的日常更新預設使用官方 GitHub Release。已追蹤 Gitea 分支的主機可用 `sudo bash update_clock.sh --upstream` 單次更新；Docker 保留原本的更新、診斷與復原入口。
- 時鐘頁會辨識伺服器的顯示資源版本。已載入本版的同來源頁面可在顯示程式更新後重新載入；平常儲存樣式會在下一次同步時套用。
- 支援的瀏覽器可將時鐘安裝為獨立視窗。管理頁在小螢幕提供可收合選單，群組加入頁可顯示 QR Code 或複製加入連結。
- EE04 桌鐘的 ESPHome 韌體與使用手冊已納入原始碼。

## 升級

Linux 與 Docker 主機請先備份資料。自用更新金鑰、啟用主機更新服務與復原步驟見[更新維護文件](https://github.com/kcayut/webclock/blob/v1.5.1/doc/operations/update-operations.md)。Home Assistant App 由 Supervisor 更新，HACS 整合與卡片由 HACS 更新。

已經開啟舊時鐘頁的 iPad，升級後請在 Safari 重新整理一次，再從管理頁選擇樣式並按「儲存樣式」。
