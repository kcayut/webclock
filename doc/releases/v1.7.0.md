# WebClock 1.7.0

## 這一版的重點

- **用自己的音訊設定網頁鬧鐘。** 在「系統 → 聲音設定」匯入 MP3、WAV、M4A、M4R 或 OGG，拖曳選取範圍、試聽並儲存，再從鬧鐘排程選擇。原始音訊限 8 MiB、5 分鐘並留在瀏覽器。伺服器接收單聲道 WAV 片段，通過格式、長度與容量檢查後才儲存。M4A／M4R 與 OGG 的匯入取決於瀏覽器是否支援該編碼。
- **管理已儲存的鈴聲。** 每個帳號可存 8 段，可改名、建立副本、剪輯副本或批次刪除。原鈴聲及其排程會在另存副本後繼續使用。完整備份包含已儲存的鈴聲。
- **預覽並調整響鈴時的提示。** 在「系統 → 閃光與震動」選擇緩慢閃動、固定亮框或關閉邊框。支援震動的瀏覽器可在響鈴時短震兩下。[網頁鬧鐘操作說明](https://github.com/kcayut/webclock/blob/v1.7.0/doc/guides/guide.md#在-ipad-使用網頁鬧鐘)

## 更新

Linux 與 Docker 主機請先備份資料。Server 需要 Flask 3.1 或更新版本，請透過對應的安裝方式更新相依套件。Home Assistant App 透過 Supervisor 更新，整合與卡片透過 HACS 更新。[更新維護與復原](https://github.com/kcayut/webclock/blob/v1.7.0/doc/operations/update-operations.md)

若 1.6 版安裝將 `NOTES_FILE` 指向狀態目錄下的 `ringtones.json`，請在升級前停止 WebClock，備份並改名現有提醒檔，再將 `NOTES_FILE` 改為新路徑。使用預設提醒檔路徑的安裝可沿用一般更新流程。
