# WebClock 1.3.0

本版整理管理頁與提醒表單，並改善顯示時間區間的選取流程。Server、Docker、HA App、HACS 整合與卡片使用相同版號。

## 更新重點

- 管理頁改為提醒、顯示來源與訂閱來源分頁，常用設定優先顯示，降低版面密度。
- 裝置與群組管理改用抽屜與分頁，保留既有指派、版本衝突與草稿保護。
- 顯示時間區間提供年／月／週檢視，可直接輸入開始與結束日期，也能拖曳選取。
- 週檢視完整顯示 00:00–24:00；拖曳時在滑鼠旁顯示目前範圍，放開後保留選取結果。
- 區間模式預設展開；新增提醒表單的「清除」需經警告視窗確認，才會重設所有輸入。
- 一般文字提醒與指定群組／裝置的投遞行為維持不變。

## 既有安裝升級

更新前請先保存完整備份。

Linux 在既有安裝目錄執行：

```bash
sudo bash update_clock.sh
```

Docker 使用固定版本入口：

```bash
sudo bash docker_update.sh --check
sudo bash docker_update.sh
```

HA 請先備份，更新 App 後再更新 HACS 整合、重啟 HA 並重新載入卡片。完整流程見[更新維護](https://github.com/kcayut/webclock/blob/v1.3.0/doc/operations/update-operations.md)。

## 下載與新安裝

[完整安裝指南](https://github.com/kcayut/webclock/blob/v1.3.0/doc/installation.md)提供 Linux／Raspberry Pi、Docker、HA App、HACS 與離線時鐘步驟。

| 檔案 | 用途 |
| --- | --- |
| `install.sh` | 固定安裝本版的新安裝入口 |
| `portable_docker_update.sh` | 舊 Docker 升級與同版 worker／救援維護 |
| `webclock-1.3.0.tar.gz` | Server 程式與 Docker 部署檔 |
| `webclock-clock-1.3.0.zip` | 完整解壓後開啟 `index.html` 的離線時鐘 |
| `SHA256SUMS` | 上述下載檔的 SHA256 核對值 |

容器映像：`ghcr.io/kcayut/webclock:1.3.0`、`ghcr.io/kcayut/webclock-addon:1.3.0`；提供 `linux/amd64` 與 `linux/arm64`。

## 驗證界線

HA App 仍為 `experimental`。Docker Desktop、NAS、rootless／遠端 daemon 不在更新器支援範圍。CI、公開下載驗證與實機驗收分開記錄；HA OS 商店／HACS 實際更新、實體 ARM、斷電、音訊及舊 iPad 仍需實機驗證。[最新發行證據](https://github.com/kcayut/webclock/blob/main/doc/ha-release.md)
