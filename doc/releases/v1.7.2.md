# WebClock 1.7.2

本版接續正式版本 1.7.0。`v1.7.1` 僅保留原 Git 標籤，未正式發布。

## 這一版的重點

- **新增微雪 4.2 吋 RLCD 桌鐘。** 400 × 300 橫向畫面可顯示板載 SHTC3 溫濕度與電池電壓，三鍵可離線設定時間與每日鬧鐘。[RLCD 韌體與使用手冊](https://github.com/kcayut/webclock/tree/v1.7.2/firmware/rlcd-clock)
- **用 microSD 自訂 RLCD 鬧鈴。** 在 FAT32 卡片根目錄放入 `alarm.wav`，可用於本機每日鬧鐘與遠端有聲排程。無卡、缺檔或讀取失敗時，桌鐘播放內建提示音。[音檔格式與換曲方式](https://github.com/kcayut/webclock/blob/v1.7.2/firmware/rlcd-clock/AUDIO.md)
- **每台桌鐘各自設定語言和顯示內容。** EE04 與 RLCD 預設使用英文，可在「Display settings → Language」切換繁體中文或日文。每台可離線設定時間格式、日期格式，以及是否顯示鬧鐘狀態、文字提醒及行事曆。RLCD 另可分別開關電池電壓和溫濕度顯示。[桌鐘顯示設定](https://github.com/kcayut/webclock/blob/v1.7.2/firmware/README.md#設定每台桌鐘的顯示內容)
- **在網頁選擇提醒的傳送對象。** 選定群組或裝置後，只有符合條件的配對裝置會收到提醒。未指定對象時，配對裝置依內容指派接收，個人模式的公開時鐘在啟用本機提醒時也會收到。[文字提醒與裝置傳送](https://github.com/kcayut/webclock/blob/v1.7.2/doc/api/server-api.md)

## 更新

Linux 與 Docker 主機請先備份資料，再依各自的更新方式操作。Home Assistant App 透過 Supervisor 更新，整合與卡片透過 HACS 更新。[更新維護與復原](https://github.com/kcayut/webclock/blob/v1.7.2/doc/operations/update-operations.md)

桌鐘韌體由同版原始碼取得，請依板型編譯、刷入。要獨立切換文字提醒和行事曆，請更新服務端及桌鐘韌體。兩款桌鐘實機驗收仍待完成。[桌鐘韌體指南](https://github.com/kcayut/webclock/tree/v1.7.2/firmware)
