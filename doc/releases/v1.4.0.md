# WebClock 1.4.0

Server、Docker、HA App、HACS 整合與卡片使用相同版號。

## 更新重點

- 常用顯示設定提供秒數、日期、日期格式與星期；預設關閉秒數、顯示日期與星期，日期格式為 `m/d`。
- 行事曆與文字提醒可設定每則顯示時間（1–300 秒，預設 5 秒），並選擇淡入淡出、左滑或上滑，預設淡入淡出。
- 鬧鐘編輯依觸發方式與重複規則顯示相關欄位，支援指定群組／裝置，並統一摘要時間格式與驗證訊息。
- 行事曆聯動鬧鐘依所選行事曆觸發，不疊加固定重複或假日過濾；鬧鐘列表提供略過、恢復與刪除操作。
- 網頁鬧鐘每次響鈴最長一小時，逾時自動停止。
- 更新健康檢查支援新增顯示預設值，保留升級前的設定比對；文件以現有功能與繁體中文敘述。

## 既有安裝升級

更新前請先保存完整備份。

Linux 在既有安裝目錄執行：

```bash
sudo bash update_clock.sh
```

Docker 使用固定版本入口：

```bash
sudo bash docker_update.sh --check
sudo bash docker_update.sh
```

HA 請先備份，更新 App 後再更新 HACS 整合、重啟 HA 並重新載入卡片。完整流程見[更新維護](https://github.com/kcayut/webclock/blob/v1.4.0/doc/operations/update-operations.md)。

## 下載與新安裝

[完整安裝指南](https://github.com/kcayut/webclock/blob/v1.4.0/doc/installation.md)提供 Linux／Raspberry Pi、Docker、HA App、HACS 與離線時鐘步驟。

| 檔案 | 用途 |
| --- | --- |
| `install.sh` | 固定安裝本版的新安裝入口 |
| `portable_docker_update.sh` | 舊 Docker 升級與同版 worker／救援維護 |
| `webclock-1.4.0.tar.gz` | Server 程式與 Docker 部署檔 |
| `webclock-clock-1.4.0.zip` | 完整解壓後開啟 `index.html` 的離線時鐘 |
| `SHA256SUMS` | 上述下載檔的 SHA256 核對值 |

容器映像：`ghcr.io/kcayut/webclock:1.4.0`、`ghcr.io/kcayut/webclock-addon:1.4.0`；提供 `linux/amd64` 與 `linux/arm64`。

## 驗證界線

HA App 仍為 `experimental`。Docker Desktop、NAS、rootless／遠端 daemon 不在更新器支援範圍。CI、公開下載驗證與實機驗收分開記錄；HA OS 商店／HACS 實際更新、實體 ARM、斷電、音訊及舊 iPad 仍需實機驗證。[最新發行證據](https://github.com/kcayut/webclock/blob/main/doc/ha-release.md)
