# WebClock 1.2.0

本版新增 Docker 安全更新與離線救援，補修 Linux／Docker 的備份、安裝及失敗復原流程。Server、Docker、HA App、HACS 整合與卡片使用相同版號。

## 更新重點

- Docker 更新先核對 Compose 身分、運行版本與映像，再冷備份、固定不可變 image ID 並確認健康；備份副本與複製前後資料必須一致。
- 新版未改寫資料時可回退原映像；資料已變更或交易不明時停止並回報 `manual_recovery`，保留現有資料與備份。健康確認後才恢復容器重啟策略。
- 新增獨立 Docker 更新入口、離線救援、備份清理預覽，以及 Linux/systemd 的 worker 啟用、受保護目錄遷移與 worker 換版。新註冊的自動安裝預設關閉，既有選擇保留。
- 修正裸機回退失敗仍運行、worker 寫入狀態失敗未正確暫停，以及 shell `--help` 意外啟用服務。安裝核對實際版本，提醒檔路徑不得與帳號／授權／還原資料重疊。
- 修正官方 Compose 預設設定被誤判，以及 managed Docker 新安裝建立管理員失敗。
- HA 整合顯示實際 Server／Integration 版本與對齊狀態；舊卡片提示重新載入。HA App／HACS 仍使用各自原生更新入口。
- 整理安裝與更新腳本；原始碼中的可攜式入口集中在 `scripts/update/`，公開下載名稱保持不變。

## 既有安裝升級

更新前先保存完整備份。Linux 在既有安裝目錄執行安全更新器；首次從 v1.1.0 升級可使用：

```bash
sudo bash update_clock.sh && sudo bash scripts/enable_updates.sh
```

舊 Docker 安裝可直接下載新版獨立入口；先將路徑換成實際安裝目錄：

```bash
curl -fsSL https://github.com/kcayut/webclock/releases/download/v1.2.0/portable_docker_update.sh -o /tmp/webclock-docker-update.sh
sudo bash /tmp/webclock-docker-update.sh --project /實際安裝路徑 --check
sudo bash /tmp/webclock-docker-update.sh --project /實際安裝路徑
```

CLI 需要宿主機 Python 3.9+，支援官方單服務 Compose 與本機系統 Docker；網頁控制另需 Linux/systemd 及明確啟用。不要重跑新安裝器覆蓋原目錄，也不要改用完整備份還原作一般升級。HA 先備份並更新 App，再更新 HACS 整合、重啟 HA 與重新載入卡片。[完整維護流程](https://github.com/kcayut/webclock/blob/v1.2.0/doc/operations/update-operations.md)

## 下載與新安裝

[完整安裝指南](https://github.com/kcayut/webclock/blob/v1.2.0/doc/installation.md)提供 Linux／Raspberry Pi、Docker、HA App、HACS 與離線時鐘步驟。

| 檔案 | 用途 |
| --- | --- |
| `install.sh` | 固定安裝本版的新安裝入口 |
| `portable_docker_update.sh` | 舊 Docker 升級與同版 worker／救援維護 |
| `webclock-1.2.0.tar.gz` | Server 程式與 Docker 部署檔 |
| `webclock-clock-1.2.0.zip` | 完整解壓後開啟 `index.html` 的離線時鐘 |
| `SHA256SUMS` | 上述下載檔的 SHA256 核對值 |

容器映像：`ghcr.io/kcayut/webclock:1.2.0`、`ghcr.io/kcayut/webclock-addon:1.2.0`；提供 `linux/amd64` 與 `linux/arm64`。

## 驗證界線

HA App 仍為 `experimental`。Docker Desktop、NAS、rootless／遠端 daemon 不在本版更新器支援範圍。CI、公開下載驗證與實機驗收分開記錄；HA OS 商店／HACS 實際更新、實體 ARM、斷電、音訊及舊 iPad 仍需實機驗證。[最新發行證據](https://github.com/kcayut/webclock/blob/main/doc/ha-release.md)
